## 🌿 Theme 01: Plants · 核心启蒙诗歌

```text
Plants

Roots go down beneath the ground,
根系深深扎入泥土，

Drink up water, safe and sound.
汲取清水，安然茁壮。

Stem stands straight and grows so tall,
枝干笔直，高高生长，

Carries water, one and all.
输送雨露，滋养八方。

Green leaves catch the sunny light,
翠绿叶片，拥抱阳光，

Make the food day after night.
日夜劳作，积蓄能量。

Pretty flowers open wide,
美丽花朵，肆意绽放，

Seeds are hidden deep inside.
小小种子，深藏心房。
```

## 🌟 核心功能亮点

1. 📖 **Poem Karaoke 沉浸剧场**：全诗一键卡拉OK高亮伴读、单句点读、🐇 1.0x / 🐢 0.7x 慢速双速发音切换、中英双语自由隐藏；
2. 🔬 **4 大深度浅出科学探索站**：
   - 地下吸水特工（根 / Root Hairs / 抓地抗风）
   - 摩天水梯（茎 / 导管 Xylem / 芹菜红墨水实验）
   - 太阳能美食厨房（叶 / 光合作用 Photosynthesis 公式）
   - 蜜蜂派对与生命胶囊（花 / 传粉 Pollination / 种子萌发 WOW 口诀）
3. 🔤 **超级单词魔法工坊 (Word Magic Lab)**：
   - 音节拆分积木（如 `be·neath`, `car·ries`, `flow·ers`, `pho·to·syn·the·sis`）
   - 地道成语与习语解读（`safe and sound`, `one and all`）
   - 自然拼读规则与变形记（`leaf` ➔ `leaves`）
4. 🎮 **三大儿童互动小游戏 (Kids Arcade)**：
   - 🌱 **拼写小萌芽 (Spelling Sprout)**：输入字母拼词，伴随动画一步步破土发芽、抽茎、展叶、开花！
   - 🃏 **翻牌记忆花园 (Memory Match)**：图文趣味配对，锻炼短时记忆与词义联想；
   - 🧠 **植物小学者问答 (Botanist Quiz)**：4 道情境化闯关小测验，通关即可收集自然宝石。
5. 🏆 **皇家自然小学者证书 (Junior Botanist Certificate)**：通关可输入名字，生成专属成就证书与撒花庆祝。
